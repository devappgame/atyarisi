# At Yarışı – Tanıtım Sitesi ve Gizlilik Politikası

Bu repo, **At Yarışı** oyununun tanıtım sayfasını ve Google Play / App Store için gerekli gizlilik politikasını içerir. Oyunun kaynak kodu bu repoda değildir.

- Ana sayfa: `index.html`
- Gizlilik politikası: `privacy.html`
- Stil: `style.css`
- Görseller: `assets/`

GitHub Pages ile yayınlanır (kök dizin, `main` dalı).
